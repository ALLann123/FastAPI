=====================RAG=====================
- AI assistant should:
	> Read documents
	> Create a vector database
	> retrieve relevant information
	> Answer questions using AI agents
- Goals
> Read PDF, TXT and Markdown documents
> Split documents into smaller chunks
> Convert chunks into numerical embeddings
> Store embeddings in a vector db
> Search for relevant information using semantic similarity
> Use LLM to generate answers based on retrieved information
> Maintain conversational context
> LangGraph to control the agent's workflow
> Cite the documents used to generate its answers.

N/B: The vector DB doesnot contain an intelligent chatbot.
Stores numerical representations of information and allows us to retrieve
relevant content.
LLM handles answer generation, while LangGraph orchestrates the workflow.

==================UNdersTanding===============
RAG stands for Retrieval-Augmented Generation
Combines:
1. Retrieval--> Finding information relevant to a user's question.
2. Generation--> Using an LLM to formulate an answer using the information.
- Imagine we have 100 PDF documents about cybersecurity. You ask:
	What are the common techniques used in API enumeration?
We get citation of where in the documents it got the answers instead
of relying on its training knowledge.

===========A RAG Application works=========
User/Agent asks a question
	"What are the common techniques used in API enumeration?"
1. Retrieval
- Search the vector database for relevant document chunks
Retrieved Information
	> Endpoint discovery
	> HTTP method enumeration
	> Parameter fuzzing
	> API version discovery

2. Generation
- Send the question and retrieved information to the LLM

3. Final Answer
- The assistant produces an answer grounded in the retrieved documents and
identifies its sources.

==============Concepts==============
1. Document Loader====> Reads PDFs, text files, etc
2. Chunking =====> Splits large documents into smaller pieces
3. Embeddings====> Converts text into numerical vectors
4. Vectore database===> Stores and indexes those vectors
5. Retriever======> Finds relevant chunks
6. LLM======> Generates the final answer.

from langchain_ollama import OllamaEmbeddings


class EmbeddingGemma:

    def __init__(self):
        print("[EMBEDDINGS] Connecting to Ollama EmbeddingGemma-300M...")

        self.model = OllamaEmbeddings(
            model="embeddinggemma:300m"
        )

        print("[EMBEDDINGS] Model connected successfully.")

    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        """
        Convert document chunks into vectors.
        """

        vectors = self.model.embed_documents(texts)

        return vectors

    def embed_query(self, text: str) -> list[float]:
        """
        Convert a user query into a vector.
        """

        vector = self.model.embed_query(text)

        return vector


if __name__ == "__main__":

    embeddings = EmbeddingGemma()

    document = "API security involves authentication and authorization."

    query = "How can I protect an API?"

    doc_vector = embeddings.embed_documents([document])
    query_vector = embeddings.embed_query(query)

    print("\nDocument dimensions:", len(doc_vector[0]))
    print("Query dimensions:", len(query_vector))

    print("\nDocument vector:", doc_vector[0][:10])
    print("Query vector:", query_vector[:10])

==========Understanding CHunking===============
- Imagine a 100-page PDF
We cannot pass it as one input to our model
We split it into smaller pieces
The process is called chunking
- Two important parameters:
	chunk_size-----> maximum target size of each chunk
	chunk_overlap---> Amount of text shared between consecutive chunks
Why overlap?
 Not to lose the context connecting two statements.
- First implementation we'll use chunk_size of 1000 characters and overlap
of 150 characters(tune this later)

*************************ingest.py*************************************
import time
from pathlib import Path
from uuid import NAMESPACE_URL, uuid5

from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_chroma import Chroma
from pypdf import PdfReader

from src.embeddings import EmbeddingGemma


DOCUMENT_DIR = Path("data/documents")
DB_DIR = "./chroma_db"
BATCH_SIZE = 32


def load_pdf(file_path: Path) -> list[Document]:
    """One Document per page, same shape PyPDFLoader produced."""
    reader = PdfReader(str(file_path))
    return [
        Document(
            page_content=page.extract_text() or "",
            metadata={"source": file_path.name, "page": index},
        )
        for index, page in enumerate(reader.pages)
    ]


def load_text(file_path: Path) -> list[Document]:
    return [
        Document(
            page_content=file_path.read_text(encoding="utf-8"),
            metadata={"source": file_path.name},
        )
    ]


def load_documents() -> list[Document]:
    documents = []
    for file_path in sorted(DOCUMENT_DIR.iterdir()):
        suffix = file_path.suffix.lower()

        if suffix == ".pdf":
            documents.extend(load_pdf(file_path))
        elif suffix in (".txt", ".md"):
            documents.extend(load_text(file_path))

    # Drop empty pages (e.g. scanned PDFs with no text layer)
    return [doc for doc in documents if doc.page_content.strip()]


def split_documents(documents):
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=1000,
        chunk_overlap=150,
    )
    return splitter.split_documents(documents)


def create_vector_store(chunks):
    embeddings = EmbeddingGemma()

    vector_store = Chroma(
        collection_name="knowledge_base",
        embedding_function=embeddings,
        persist_directory=DB_DIR,
    )

    ids = [
        str(
            uuid5(
                NAMESPACE_URL,
                f"{doc.metadata.get('source', '')}-"
                f"{doc.metadata.get('page', '')}-"
                f"{doc.page_content}",
            )
        )
        for doc in chunks
    ]

    # Batched so progress is visible and one failure doesn't lose everything
    for start in range(0, len(chunks), BATCH_SIZE):
        end = start + BATCH_SIZE
        vector_store.add_documents(documents=chunks[start:end], ids=ids[start:end])
        print(f"  embedded {min(end, len(chunks))}/{len(chunks)}")

    return vector_store


if __name__ == "__main__":
    start = time.perf_counter()

    print("[1] Loading documents...")
    documents = load_documents()
    print("Loaded documents:", len(documents))

    print("[2] Splitting documents...")
    chunks = split_documents(documents)
    print("Generated chunks:", len(chunks))

    print("[3] Creating vector database...")
    vector_store = create_vector_store(chunks)
    elapsed = time.perf_counter() - start

    print("[SUCCESS] Ingestion completed!")
    print("Stored chunks:", vector_store._collection.count())
    print(f"\nElapsed time: {elapsed:.2f} seconds")
