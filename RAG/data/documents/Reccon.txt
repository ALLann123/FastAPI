======Recon Workflow====
- Tools are powerful and free
- Reconnaissance is the backbone of bug bounty hunting.


======Step 1: Asset Discovery(Domains & Subdomains)======
- Tools we can use
	AssetFinder
	Subfinder
	Amass
	crt.sh
	dnsx ---> collecting records of subdomains
	shosubgo ----> extracts subdomains from shodan
- Lets use Subfinder:
	kali> subfinder -d target.com -o subdomains.txt
Command above finds subdomains from the domain
	kali> dnsx -l subdomains.txt -a -resp-only -o resolved.txt
Resolves the subdomains to there respective IPs.

=====Step 2: Probing & Port Scanning=======
- Tools for this:
	httpx
	naabu---> port  scanning tool written in GOlang
	masscan
Commands:
	kali> naabu -l resolved.txt -top-ports 1000 -o ports.txt
	kali> httpx -l resolved.txt -title -tech-detect -status-code -o livehosts.txt
- To fingerprint the web servers using httpx add the flag:	
	`-web-server`


====Step 3: Tech Stack & Framework Detection=======
- Below are some tools:
a. Wappalyzer: Browser extension and CLI tool for tech detection
b. Nuclei Templates: Utilizes nuclei with technologies-detect templates for 
identification.
c. BuiltWith: Online tool with API for identifying technologies.
Why?
- Knowing if it's running Wordpress, Laravel, NGINX, or Apache can help you
narrow down target-specific attack vectors.


====Step 4: Crawl & ENdpoint Discovery=====
- Which tool should be used for web scraping and data extration?
a. Katana: Best for Js Heavy websites, effectively retrieves content
b. Gau: Ideal to uncover new URLs from various sources
c. Paramspider: Crucial for extracting parameters from URLs useful for identifying
attack vectors.
d. Waymore: Designed for exploring web applications, provides insights into
structure and functionality.
	kali> katana -u https://target.com -js-crawl -o endpoints.txt
	kali> gau target.com | tee gau.txt
- Combine all output & Filter unique parameters for testing

====Step 5: Parameters + Secrets Hunting======
- TOols:
a. gf: Efficient pattern searching in files
b. secretfinder: Identifies sensitvie information in code
c. getJS: Retrieves Javascript files from web apps
	kali> gf xss gau.txt > xss-params.txt
- CHeck URLs with params like "redirect=", "url=", "file=", "callback="--> goldmine
for bugs!

====Step 6: JS Recon======GOLDMINE
- Web data extraction cycle:
	Retrive JS---> extract Hyperlinks---> Analyze JS---RESTART
- COmmand:
	kali> getJS --url https://target.com --output jurls.txt
Look for:
	> API Endpoints.
	> Secrets/tokens.
	> Internal links.
	> Hidden paths.

====Step 7: CDN, WAF, and DNS Intel======
- Tools:
a. asnlookup: Provides ASN information for network analysis.
b. dnsdumpster: Offers DNS record analysis for domain mapping
c. Securitytrails API:Delivers comprehensive domain and IP data.
d. SHodan and Censys---> Search Engine for internet connected devices.
- Understanding CDN/WAF Helps:
	> Understand if requests are reaching the origin server.
	> Bypass rate limits.
	> Identify weak misconfigured edge services.

nuclei -l $target/recon/live_jarm.txt -t ~/nuclei-templates/ -es info -o $target/recon/nuclei_tech.txt

# Phase 2: JS-Driven Intel
getJS --url-file $target/recon/live_jarm.txt --output $target/js/js_urls.txt
python3 SecretFinder.py -i $target/js/js_urls.txt -o $target/js/secrets.json

# Phase 3: Attack Surface Expansion
waymore -i $target -o $target/recon/waymore  
gf xss $target/recon/waymore/waymore.txt | qsreplace -a | dalfox pipe --silence

# Phase 4: Cloud Exploit Prep
s3scanner scan -f $target/recon/subs.txt -o $target/cloud/s3.txt  
cdk-go run --target $target -o $target/cloud/cdk_report.html

# Phase 5: AI-Powered Correlation
