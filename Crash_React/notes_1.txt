====================Foundations===================
GOAL- Build a page from small, reusable React Components

What is REACT?
- Is a Js library for building UIs
- Central ideas behind it are:
	1. Components
> You split the page into small, independent pieces, such as header, a card or a 
button
	2. Declarative UI
> Describe what the screen should look like for your data, and React updates the 
browser page(the DOM) to match.

=====Your first Component======
- A component is a JS function that returns a UI. 
- Replace everything in src/App.jsx

}

***********************************************************
- Component name starts with a capital letter "App", "Welcome"
- Define components at the top level of a file never inside another component
- When the returned UI covers several lines, wrap it in parantheses()

=============JSX=============
- JSX is the html like syntax inside your Js. Looks like HTML but stricter.
Rule 1: Return one parent element
*************wrong*********************
return (
	<h1>Title<h1/>
	<p>Text</p>
);
***************************************
- The above is wrong
- Should be wrapped in a fragment as one element being returned:
*************Correct*******************
return (
	<>
		<h1>Title</h1/>
		<p>Text</p>
	<>
);
***************************************

Rule2: Close evert tag
<img src="photo.jpg" alt="A photo" />
<input type="text" />
<br />

Rule3: Use { } for JS
*********************App.jsx*************************
//write another function 
function Welcome(){
  return <p>Welcome to the Crash Course</p>
}


function App(){
  const name='Brian';
  const year=2026;
  const avatar='https://placehold.co/100';
  return(
    <div>
      <h1>Hello, React</h1>
      <Welcome/>
      <Welcome/>
      <br/>
      <h2>{name.toUpperCase()}</h2>
      <p>Born in {year - 21}</p>
      <img src={avatar} alt={`Avatar of ${name}`} />
    </div>
  );
}

export default App;
************************************************
- Inside the {} put any JS expressions that produces a value. Statements such as
if/for are not allowed there.


=======Props=======
- Props pass data from a parent component to a child. They work like function
arguments.
**************************App.jsx*************************
//write another function 
function Welcome(){
  return <p>Welcome to the Crash Course</p>
}

//Component with a prop
function Greeting({name, role}){
  return <p>{name} is an {role}</p>
}

function App(){
  const name='Brian';
  const year=2026;
  const avatar='https://placehold.co/100';
  return(
    <div>
      <h1>Hello, React</h1>
      <Welcome/>
      <Welcome/>
      <br/>
      <h2>{name.toUpperCase()}</h2>
      <p>Born in {year - 21}</p>
      <img src={avatar} alt={`Avatar of ${name}`} />

      <h2>Occupation</h2>
      <Greeting name={name} role="AI Engineer"/>
    </div>
  );
}

export default App;
**************************************************
- We have passed different types into our function. Use quotes for plain strings and
braces for everything else(other variables, integers, floats)
- We can also set default values as prop holders:
***************************************
function Button({ text = 'Click me', color = 'blue' }) {
  return <button style={{ backgroundColor: color, color: 'white' }}>{text}</button>;
}
****************************************


=====The Children Prop=======
- Anything placed between component's opening and closing tags arrives as children
Useful for wrappers such as cards and layouts.
**********************App.jsx*************************

function Card({children}){
  return <div className="card">{children}</div>
}

function App(){

  return(
    <Card>
      <h2>Title</h2>
      <p>This content is passed as children</p>
    </Card>
  );
}

export default App;
**********************************************************


========Props are read-only========
- A component must never change its props
*********************************
function Price({ amount }) {
  // Wrong: amount = amount * 1.16;
  const total = amount * 1.16; // Right: create a new value
  return <p>Total: {total.toFixed(2)}</p>;
}
*********************************
- Get to improve on this when we get to state. Data can change over time.

=========Conditional Rendering===========
- Use ordinary JS to decide what to show
- Ternary: choose between two things
*****************************App.jsx********************************

function Dashboard({isLoggedIn}){
  if(!isLoggedIn){
    return <p>Please Log in.</p>
  }
  return <h1>Your Dashboard</h1>
}

function Products({inStock}){
  return <p>{inStock ? 'Available':'Sold out'}</p>
}

function App(){
  const isLoggedIn=true;
  const instock=true;
  return(
    <div>
      <Dashboard isLoggedIn={isLoggedIn}/>
      <Products inStock={instock}/>
    </div>
  );
}

export default App;
****************************************************************
- To render nothing at all, a component can return null.


=============Lists and Keys=============
- .map() to turn an array of data into an array of elements.
**********************************App.jsx**********************************

const fruits=[
  {id:'f1', name:'Mango'},
  {id:'f2', name:'Banana'},
  {id:'f3', name:'Passion fruit'},
];

function App(){
  return (
    <ul>
      {fruits.map((fruit)=>(
        <li key={fruit.id}>{fruit.name}</li>
      ))}
    </ul>
  )
}

export default App;
***************************************************************************

======Why keys Matter======
- A key helps React track which item is which when a list changes

======Thinking in React======
- When given a page to build
	1. Draw boxes arounf each part of the design. Each box is a possible component
	2. Name each box
	3. Arrange them as a tree of parents and children
	4. Decides what data each one needs. That data becomes its props
	5. Build it with fixed data first.
